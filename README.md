# The Thrum

A D&D 5e campaign setting where magic works like physics. Instead of spell slots and a spell list, players learn a handful of laws about how magical energy (Motes) moves, then invent their own spells from them.

**Version 2.0**

- [Player's Guide](PLAYERS_GUIDE.md): everything you need to play a caster
- [Advanced Techniques](ADVANCED_TECHNIQUES.md): optional modules (metals, gems, healing, mind magic and more), learned as the story calls for them
- [DM Reference](DM_REFERENCE.md): Flux, stored energy, power scale, the darker rules, and the LLM advisor
- [Examples](EXAMPLES.md): worked test runs (written for version 1.4)
- [Open questions](OPEN_QUESTIONS.md): what is still undecided
